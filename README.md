## Update the live website
1. Extract `VLuck_Labs_V5_3D_Premium.zip`.
2. Open the existing GitHub repository: `vluck-labs-website`.
3. Choose **Add file → Upload files**.
4. Upload all extracted files to the repository root.
5. Commit directly to the `main` branch.
6. Vercel will automatically redeploy the latest commit.
7. No DNS changes are required.
